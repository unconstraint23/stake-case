




这个测试文件涵盖了以下主要流程和验证点：

### 测试覆盖的流程：

1. **合约部署和初始化**
    - 验证合约正确初始化
    - 验证管理员权限设置
    - 验证初始参数设置

2. **池子管理**
    - 添加ETH池和ERC20池
    - 更新池子信息
    - 设置池子权重

3. **质押操作**
    - ETH质押
    - ERC20代币质押
    - 验证最小质押金额限制
    - 验证不能向错误的池子存入ETH

4. **提取操作**
    - 请求提取质押
    - 验证提取金额限制
    - 在解锁期后提取质押资产

5. **奖励机制**
    - 计算待领取奖励
    - 领取奖励
    - 验证奖励正确发放

6. **管理员功能**
    - 暂停/恢复提取功能
    - 暂停/恢复领取奖励功能
    - 更新区块参数
    - 更新每区块奖励

### 验证要点：

1. **状态更新顺序**：确保在操作前先更新池子和用户状态
2. **奖励计算准确性**：验证奖励按权重和质押量正确分配
3. **安全机制**：验证各种限制和权限控制
4. **事件触发**：验证所有重要操作都触发了正确的事件
5. **边界条件**：测试各种边界情况和错误处理

要运行这个测试，您需要确保：
1. 在 `hardhat.config.js` 中正确配置了测试环境
2. 安装了必要的依赖包（chai等）
3. 在项目根目录运行 `npx hardhat test` 命令

```shell
# 运行所有测试
npx hardhat test test/CompleteTest.js

# 运行特定测试套件
npx hardhat test test/CompleteTest.js --grep "MetaNode Token Tests"

# 详细输出
npx hardhat test test/CompleteTest.js --verbose
 ```
